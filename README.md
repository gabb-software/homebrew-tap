# Homebrew Tap for Gabb Software

This repository contains Homebrew formulae for Gabb Software projects.

## Installation

```bash
brew tap gabb-software/tap
brew install gabb-cli
```

Or install directly:

```bash
brew install gabb-software/tap/gabb-cli
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `gabb-cli` | Fast local code indexing CLI |

## Updating

```bash
brew update
brew upgrade gabb-cli
```

## Issues

For issues with the formulae, please file an issue in this repository.

For issues with gabb-cli itself, please file an issue at [gabb-software/gabb-cli](https://github.com/gabb-software/gabb-cli/issues).
